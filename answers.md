1. **Чому важливо вказувати `user.name` та `user.email`?**
   Щоб було зрозуміло, хто саме зробив коміт. Коли над проєктом працює кілька людей, ці дані показують автора кожних змін, а ще завдяки пошті GitHub прив'язує коміти до твого акаунту.

2. **Яка різниця між `git pull` і `git fetch`?**
   `git fetch` просто скачує оновлення з GitHub на комп'ютер, щоб ти міг подивитися, що нового з'явилося, але твої поточні файли не чіпає. А `git pull` одразу і скачує зміни, і зливає їх з твоїм кодом у поточній гілці.

3. **Як скасувати останній коміт, не втрачаючи зміни у файлах?**
   Треба ввести команду `git reset --soft HEAD~1`. Вона прибере сам коміт з історії, але весь код, який ти написав, залишиться на місці і нічого не пропаде.
